# CIVIRA – Civic Issue Reporting System

## About the Project

CIVIRA is an AI-powered Civic Issue Reporting System designed to help citizens report civic problems through images.

The system allows users to upload images of civic issues, automatically classify the reported issue, verify the submitted information, and track the status of the complaint.

The project combines Machine Learning, Computer Vision, and web technologies to create a smarter and more efficient civic issue reporting platform.

## Objectives

- Allow citizens to report civic issues digitally.
- Automatically identify the type of civic issue from uploaded images.
- Filter irrelevant or inappropriate images.
- Detect duplicate reports.
- Assign priority to reported issues.
- Track the status of reported complaints.
- Provide an efficient platform for managing civic complaints.

## How It Works

1. User logs into the system.
2. User uploads an image of a civic issue.
3. The system analyzes the uploaded image.
4. The AI model identifies the type of civic issue.
5. The system checks whether the image is relevant and appropriate.
6. Location information is verified.
7. The system checks for duplicate reports.
8. A priority score is assigned to the issue.
9. The complaint is submitted to the system.
10. Users can track the status of their reported issue.
